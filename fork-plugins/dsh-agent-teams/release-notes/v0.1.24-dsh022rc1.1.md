# v0.1.24-dsh022rc1.1 — Harness 0.2.2 compatibility

Prerelease channel: npm `dsh022rc1`. Recommended host: Harness `0.2.2-rc.1`.

- Support Harness `0.2.2-rc.1` host-owned per-Agent model selection: a member's resolved route travels in its creation options, a saved backup route is restored as a recorded choice, and a fallback accepted after a failed request applies from the member's next step.
- Track the 0.2.2 subagent runtime, which awaits a disposable `ProjectionHandle` for each projection it registers.
- Keep the 0.2.1 generation and every earlier tested host as legacy targets: hosts without `Agent.model` keep the previous request-route override and in-step retry.
- Pin the full development host cohort to `0.2.2-rc.1` and Cordis `4.1.0`.

Validation scope and limitations: [migration record](../docs/harness-0.2.2-rc.1/README.md).

Install the published version with `dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.24-dsh022rc1.1`. This prerelease does not move npm `latest`.
