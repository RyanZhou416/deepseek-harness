# v0.1.15-dsh013alpha2.1

- Rebase every Harness peer and development dependency onto `dsh-v0.1.3-alpha.2`.
- Use alpha.2's unified symbol-keyed Host delivery adapter for Queue and Steer while preserving plugin-owned message provenance.
- Keep inactive-member delivery on Host Queue and live-member delivery on Host Steer.
- Extend the retired-member guard across the unified Host adapter and public adjacent-Agent messaging path.
- Retain the bounded unread-mailbox projection cache and the existing Team, mailbox, retired-index, Session, and attachment formats.

---

- 将所有 Harness peer 与开发依赖重基到 `dsh-v0.1.3-alpha.2`。
- 使用 alpha.2 统一的 symbol-keyed Host 投递 adapter 处理 Queue 与 Steer，同时保留插件自有消息来源。
- inactive 成员使用 Host Queue，live 成员使用 Host Steer。
- 退休成员保护同时覆盖统一 Host adapter 与公开相邻 Agent 消息路径。
- 保留有界未读 mailbox 投影缓存，以及现有 Team、mailbox、退休索引、Session 与附件格式。
