# AgentTeams v0.1.16-dsh013alpha2.1

This private fork build integrates upstream `v0.1.16-rc.1` and targets the exact DeepSeek Harness `dsh-v0.1.3-alpha.2` dependency cohort.

## Upstream changes

- Recover parked attempts once after a process restart and restore the prior capability when recovery delivery fails.
- Persist member fallback routes across cold restart.
- Require captains to use the reassignment workflow instead of claiming work for members.
- Bound plan and halt request bodies and retain the authenticated Web route gate.
- Add compact model badges, visible panel resize handles, compatibility inspection, and release verification.

## Fork guarantees

- Resident members receive Host Steer at the nearest model step; inactive members receive Host Queue for a distinct cold-resumable turn.
- Unread Captain mailbox records survive offline delivery and are claimed, steered, and acknowledged after the Captain becomes resident.
- Retired members remain available for transcript history while Host delivery and public adjacent-Agent messaging both reject new work.
- The unread-mailbox projection cache, dynamic leases, Windows directory retry budget, Alpha.2 prompt-section ordering, and Lexical composer focus target remain intact.
- The private package, peer ranges, development dependencies, and transitive DSH overrides all pin `0.1.3-alpha.2`.

## Verification

`pnpm build` and `pnpm verify` pass against the exact private dependency cohort. The verification covers legacy and modern 0.1.2 adapter probes, Alpha.2 Queue/Steer routing, fallback and parked-attempt recovery, retired-member rejection, cold Captain mailbox redelivery, HTTP request limits, dependency identity inspection, Web authentication, and the full scheduler lifecycle.
