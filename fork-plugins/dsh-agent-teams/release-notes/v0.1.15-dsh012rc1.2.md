# v0.1.15-dsh012rc1.2

- Extend the retired-member boundary to RC.1's public
  `SubagentRuntime.sendMessage()` path in addition to the Host Queue and the
  fork's optional nearest-step Host seam.
- Keep historical child catalog rows readable while preventing every supported
  Agent-to-retired-member delivery path from cold-resuming new model work.
- Add lifecycle regression coverage for public, Queue, and Host-steer delivery.
- Cache only the unread mailbox projection behind a bounded LRU keyed by file
  identity. Unchanged one-second UI polls now stat and filter pending records
  instead of rereading and reparsing permanent JSONL history.
- Invalidate the projection after append/claim/release/ack/archive/remove while
  leaving full-history reads and every on-disk byte format unchanged.

No Team state, mailbox, retired-index, Session, or attachment format changed.
