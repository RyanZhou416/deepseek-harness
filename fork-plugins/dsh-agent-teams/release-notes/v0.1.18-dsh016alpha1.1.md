# AgentTeams v0.1.18-dsh016alpha1.1

This private build integrates upstream AgentTeams `v0.1.18` and targets the exact DeepSeek Harness `dsh-v0.1.6-alpha.1` dependency cohort.

It uses the awaited `agent/created` startup event, preserves cold Captain mailbox recovery and the bounded unread-mailbox cache, and keeps the upstream v0.1.18 scheduling, next-step delivery, retired-member cleanup, and task-correction behavior. Team and mailbox files remain compatible with the upstream v0.1.18 JSON formats.
