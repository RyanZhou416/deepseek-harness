# AgentTeams v0.1.19-dsh016alpha2.1

This private build integrates upstream AgentTeams `v0.1.19` and targets the exact DeepSeek Harness `dsh-v0.1.6-alpha.2` dependency cohort.

It keeps the awaited `agent/created` initialization path, cold Captain mailbox recovery, bounded unread-mailbox cache, and unchanged Team JSON formats. The browser client follows Alpha.2 Session ownership: it derives the selected Session from `mainView` retention and opens member transcripts through `uiWorkspace` with a durable subagent address. The build also includes upstream member-start recovery for renamed or disabled delegation tools, repair-scope correction, and captain-only task amendment.
