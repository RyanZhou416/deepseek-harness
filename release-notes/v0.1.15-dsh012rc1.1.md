# v0.1.15-dsh012rc1.1

Private integration build for `RyanZhou416/deepseek-harness` at
`dsh-v0.1.2-rc.1`.

- Starts from Agent Teams `main` at `232a338fc9`, retaining the blank-optional
  input fixes, authenticated Web routes, and terminal member-failure handling.
- Applies upstream PR #124 (`098e4e97eb`) for `agent/session-start`,
  `Session.ownEvents()`, and RC.1 Host Queue compatibility.
- Uses the Harness fork's optional nearest-step Host seam when present and
  falls back to the official RC.1 Queue adapter without changing Team state.
- Guards retired members across both Host delivery paths.
- Restores cold captains before Team delivery and redelivers durable captain
  mailbox records with claim/ack/release ordering.
- Derives the prompt order from `TEAM_POLICY`, fixes the RC.1 composer focus
  selector, tolerates longer Windows directory locks, and makes the build
  cleaner path check cross-platform.

This build does not change `team.json`, mailbox JSONL, the retired-member index,
or the `.agent-teams` directory layout. Existing and archived Team data remains
compatible. The package is marked private and must not be published under the
upstream npm scope.
